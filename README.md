# README

## Introduction

This project provides an **adventure attribute** system for Minecraft servers. It is built as an extension on top of IMYVMWorldGeo, which manages geographic regions and their associated mechanics. WorldGeo-AdventureAddon introduces attributes that govern player adventure progression tied to the regional geography system.
